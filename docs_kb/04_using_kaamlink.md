# How to use KaamLink (sample)

> Sample content for demo; replace with official notifications.

**Contractors:** Tap "I need workers", speak or type the job (skill, count, date, place, wage), review the extracted card, then match and alert workers in waves.
**Workers:** Tap "I need work", record your name, trade, area, and expected wage, then confirm to save your profile.
Alerts look like WhatsApp messages — reply Yes/No (or haan / illai).
After the job, contractors can rate workers; ratings update reliability for future matches.
Use Demo mode if the internet or API is unavailable during a presentation.

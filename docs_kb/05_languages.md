# Languages and voice notes (sample)

> Sample content for demo; replace with official notifications.

KaamLink accepts Hindi, Tamil, English, and mixed Hinglish / Tanglish voice notes.
Pick a language chip (Auto / Tamil / Hindi / English) before recording for better transcription.
Trade slang such as mestri, colour wala, pipe wala, and mazdoor is normalised to standard skills.
If speech-to-text fails, type the same request in the text box — the rest of the pipeline is identical.
Alerts can be played as audio in Tamil, Hindi, or English using free on-device TTS.

# 3-minute KaamLink demo script

1. **Home (15s)** — “KaamLink matches contractors and workers from Hinglish/Tanglish voice notes using Groq Whisper + Llama and local embeddings.”
2. **Contractor (60s)** — Language chip Hindi → paste `Kal 3 mason chahiye, Chengalpattu mein, 800 per day` → Extract & match. Show job card, wage typical range, shortlist score bars.
3. **Waves (40s)** — Alert in waves of 5 → Simulate worker replies → timeline shows declines → next workers. Play ▶ TTS on one bubble.
4. **Lowball (20s)** — Try wage 500 → see warning → Adjust to median.
5. **Ask KaamLink (25s)** — “What should I do if wages are unpaid?” → answer + source filenames.
6. **Metrics (20s)** — Show LLM vs Regex chart (or Run evaluation). Mention 50-sample eval.
7. **Analytics (20s)** — Generate demo data → jobs per trade / acceptance chart.

Backup: enable **Demo mode** if Groq is slow or offline.
